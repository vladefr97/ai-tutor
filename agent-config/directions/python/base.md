# Экспертная основа: Python

Направление «Python Developer» учит писать небольшие программы на Python 3: от переменных до функций, коллекций, работы с файлами, модулей и тестов. Ученик — новичок или человек с базовыми знаниями и пробелами. Практика — задачи с кодом в личном учебном репозитории; официальные проверки — pytest-тесты платформы.

## Границы

Входит:

- установка Python 3.12+, запуск скриптов из терминала, интерактивный интерпретатор, виртуальное окружение `venv` и `pip install` на уровне «поставить pytest»;
- переменные, типы `int`, `float`, `str`, `bool`, `None`, приведение типов, ввод и вывод;
- условия, циклы `for` и `while`, `range`, `break`, `continue`;
- строки: срезы, методы, f-строки;
- коллекции: `list`, `tuple`, `dict`, `set`, перебор, генераторы списков и словарей;
- функции: параметры, значения по умолчанию, `return`, области видимости, `*args` и `**kwargs` на уровне чтения;
- исключения: `try`/`except`/`finally`, `raise`, встроенные типы ошибок;
- файлы: чтение и запись текста, `with`, модули `csv` и `json`, `pathlib`;
- модули и пакеты: `import`, свои модули, стандартная библиотека (`math`, `random`, `datetime`, `collections`);
- тесты: `assert`, pytest, запуск тестов, чтение сообщения о падении;
- введение в классы: `class`, `__init__`, методы, атрибуты — на уровне «описать простую сущность»;
- чтение чужого кода и отладка по сообщению об ошибке (traceback).

Не входит (цель с этим — вне основы, предложить ближайшую внутри):

- веб-фреймворки (Django, Flask, FastAPI), фронтенд, базы данных и ORM;
- анализ данных и ML (pandas, numpy, scikit-learn, нейросети);
- асинхронность, многопоточность, метаклассы, дескрипторы, продвинутое ООП и паттерны;
- GUI, игры, мобильная разработка, парсинг сайтов, боты с внешними API;
- подготовка к собеседованиям и алгоритмические олимпиады;
- другие языки программирования.

Ближайшие цели внутри основы для частых запросов:

| Запрос | Ближайшая цель |
|---|---|
| «Хочу анализировать данные» | обрабатывать CSV-файлы средствами стандартной библиотеки: читать, фильтровать, считать итоги |
| «Хочу сделать сайт» | писать модули с функциями и тестами — основа, на которой потом изучают веб-фреймворк |
| «Хочу автоматизировать рутину» | писать скрипты, которые обрабатывают файлы и папки |
| «Хочу бота» | писать программу с функциями, словарями и обработкой ошибок, которая отвечает на команды из консоли |

## Карта компетенций

Уровни: **начальный** — узнаёт и повторяет по образцу; **базовый** — самостоятельно решает типовую задачу; **уверенный** — решает незнакомую задачу, объясняет выбор, находит ошибку.

| № | Компетенция | Опирается на |

| P1 | Запуск программ и базовый синтаксис | — |
| P2 | Типы данных и выражения | P1 |
| P3 | Управление потоком: условия и циклы | P2 |
| P4 | Строки и коллекции | P2, P3 |
| P5 | Функции | P3, P4 |
| P6 | Ошибки и исключения | P5 |

### P1. Запуск программ и базовый синтаксис

Запускает скрипт `python file.py`, пользуется интерпретатором, понимает отступы и комментарии, читает traceback до строки с ошибкой.
Критерий освоения: запускает данный скрипт, по сообщению `SyntaxError` или `NameError` находит строку и исправляет опечатку.

### P2. Типы данных и выражения

Различает `int`, `float`, `str`, `bool`, `None`; приводит типы (`int(input())`); понимает операции, `//`, `%`, сравнения, логические операторы.
Критерий: предсказывает результат выражения с разными типами, объясняет, почему `"2" + 2` — ошибка.

### P3. Управление потоком

Пишет `if/elif/else`, циклы `for` по коллекции и `range`, `while` с условием выхода, использует `break` и `continue`.
Критерий: пишет программу, которая перебирает данные и считает итог по условию; объясняет, когда цикл закончится.

### P4. Строки и коллекции

Срезы и методы строк, f-строки; список, кортеж, словарь, множество — когда что выбрать; перебор словаря; генератор списка.
Критерий: выбирает подходящую коллекцию под задачу (подсчёт частот — словарь, уникальные — множество) и обосновывает выбор.

### P5. Функции

Объявляет функцию с параметрами и значениями по умолчанию, возвращает значение, различает `print` и `return`, понимает локальные переменные, разбивает задачу на функции.
Критерий: пишет функцию по описанию входа и выхода, которая проходит тесты на обычные и граничные случаи.

### P6. Ошибки и исключения

Читает traceback, перехватывает ожидаемые исключения (`ValueError`, `KeyError`, `FileNotFoundError`), бросает свои через `raise` с понятным сообщением, не глушит все ошибки голым `except`.
Критерий: функция корректно обрабатывает неверный ввод так, как требует условие.

### P7. Файлы и форматы данных

Читает и пишет текстовый файл через `with open`, кодировка `utf-8`; работает с `csv` и `json`; строит пути через `pathlib`.
Критерий: пишет функцию, которая читает CSV, фильтрует строки и возвращает или записывает итог.

### P8. Модули и тесты

Импортирует свои и стандартные модули, понимает `if __name__ == "__main__"`, пишет тесты pytest с `assert`, запускает их и читает отчёт.
Критерий: пишет 3–5 тестов к своей функции, включая граничный случай, и находит ошибку по упавшему тесту.

### P9. Классы (введение)

Описывает класс с `__init__` и методами, создаёт объекты, понимает `self`, различает класс и экземпляр.
Критерий: моделирует простую сущность (счёт, задача в списке дел) классом с 2–3 методами, которые проходят тесты.

## Примеры заданий

Встроенные вопросы:

- выбор одного: «Что вернёт функция без `return`?» — `None`; отвлекающие: `0`, пустая строка, ошибка;
- выбор нескольких: «Какие типы изменяемые?» — `list`, `dict`, `set`; отвлекающие: `tuple`, `str`;
- короткий ответ: «Чем `return` отличается от `print`?» — критерий: `return` передаёт значение вызывающему коду, `print` только выводит на экран.

Практика (код в репозитории, официальные тесты pytest):

- `sum_even(numbers)` — сумма чётных чисел списка, пустой список даёт 0;
- `word_count(text)` — словарь частот слов без учёта регистра;
- `read_scores(path)` — прочитать CSV с оценками и вернуть средний балл по ученику; при отсутствии файла — `FileNotFoundError` с понятным сообщением;
- класс `TodoList` с методами `add`, `done`, `pending`.

Экзамен (два варианта на одни навыки цели, задания с кодом):

- вариант А: функция, которая читает JSON со списком покупок и возвращает сумму по категориям; обработка пустого файла;
- вариант Б: функция, которая читает CSV с расходами и возвращает самую затратную категорию; обработка неверной строки.

## Цель по умолчанию и типовой план

Цель «основы Python»: **писать небольшие программы с функциями, коллекциями и файлами и проверять их тестами pytest.**

Типовой план:

1. **Первые программы** — запуск, переменные, типы, ввод-вывод (P1, P2). Практика: программа-калькулятор чаевых.
2. **Условия и циклы** (P3). Практика: подсчёт по условию в списке.
3. **Строки и коллекции** (P4). Практика: частоты слов.
4. **Функции** (P5). Практика: набор функций по описанию с тестами.
5. **Ошибки, модули и тесты** (P6, P8). Практика: функция с обработкой ошибок и своими тестами.
6. **Файлы и данные** (P7). Практика: обработка CSV.

Экзамен — задание с кодом на функции, коллекции, файлы и обработку ошибок. Классы (P9) добавляются, если цель ученика их требует.

## Типичные ошибки новичков

Пригодятся для неправильных вариантов, подсказок и разборов.

- Путает `print` и `return`; функция печатает результат вместо возврата, и тест получает `None`.
- `=` вместо `==` в условии; сравнивает строку с числом (`input()` возвращает строку).
- Неверные отступы: код после цикла оказывается внутри цикла, `return` внутри цикла завершает функцию на первой итерации.
- Ошибки на единицу с `range(len(x))` и срезами; изменяет список, по которому идёт цикл.
- Изменяемое значение по умолчанию `def f(x=[])`.
- Голый `except:` глушит все ошибки, включая опечатки.
- Открывает файл без `with` и без `encoding="utf-8"`; относительный путь от другой папки.
- Пишет тесты, которые всегда проходят (`assert True`), или проверяет только один случай.
- Путает индекс и элемент при переборе; обращается к несуществующему ключу словаря вместо `get`.
