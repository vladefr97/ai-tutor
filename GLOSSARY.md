# Tutor App

Сервис, который по запросу человека в свободной форме проводит интервью, генерирует учебный курс по любой теме и ведёт по нему.

## Language

**Ученик**:
Человек, который проходит курс. В первой версии — один на установку.
_Avoid_: пользователь, студент, юзер

**Профиль ученика**:
Предпочтения ученика о том, как с ним общаться: имя, обращение, тон, смайлики, формат объяснений — плюс пожелания в свободной форме. Заполняется один раз при первом запуске, правится в настройках. Влияет на тон агентов, но не на содержание курса.
_Avoid_: настройки, анкета, персонализация

**Наставник**:
Агент, который помогает ученику на странице темы и в каждом задании: отвечает на вопросы, разбирает незасчитанный ответ, показывает разбор. Имя ему даёт ученик. Ведёт себя согласно профилю ученика.
_Avoid_: учитель, тьютор, ассистент, помощник

**Интервью**:
Диалог в чате, в котором агент уточняет у ученика, что и зачем он хочет изучить и какой результат получить. Ведётся по методу grilling: раундами, с рекомендуемым ответом на каждый вопрос.
_Avoid_: онбординг, опрос, анкета

**Бриф**:
Итог интервью: цель, текущий уровень, желаемый результат, объём и план тем. Ученик подтверждает бриф, после чего по нему генерируется курс.
_Avoid_: ТЗ, спецификация, план

**Курс**:
Учебный материал, сгенерированный по одному брифу. Состоит из тем, идущих плоским списком. Курс не перегенерируется — вместо этого создаётся новый.

**Тема**:
Единица курса: шпаргалка и набор заданий. Темы не блокируют друг друга — ученик открывает любую.
_Avoid_: урок, модуль, глава

**Шпаргалка**:
Теоретическая часть темы в виде текста. Читается целиком до заданий.
_Avoid_: теория, лекция, конспект

**Задание**:
Единица практики внутри темы: квиз, открытый вопрос или упорядочивание. Засчитывается или явно пропускается.
_Avoid_: задача, упражнение, вопрос

**Итоговое задание**:
Последняя тема курса без шпаргалки: один открытый вопрос на применение всего курса. Оценивает модель.
_Avoid_: мини-проект, экзамен, финал

**Папка курса**:
Каталог на диске ученика, куда генератор пишет курс: `course.json`, `learner.json`, `topics/NN-slug/cheatsheet.md` и `tasks.json`. Единственный источник правды о содержании курса.
_Avoid_: репозиторий, проект, база

**Плеер**:
Артефакт Claude — страница, в которой ученик проходит курс: читает шпаргалки, решает задания, говорит с Наставником. Хранит прогресс. Один плеер на курс.
_Avoid_: приложение, тренажёр, UI

**Квиз**:
Вопрос с выбором ответа из предложенных. Проверяется без участия модели.
_Avoid_: тест, викторина

**Открытый вопрос**:
Вопрос, на который ученик отвечает свободным текстом. Ответ оценивает модель.
_Avoid_: эссе, свободный ответ

**Упорядочивание**:
Задание расставить предложенные элементы в правильной последовательности. Проверяется без участия модели.
_Avoid_: сортировка, последовательность
