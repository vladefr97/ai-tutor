# Практика по Python

Это ваш учебный репозиторий. Здесь лежат задания курса и заготовки кода. Теория — на сайте ai-tutor.

## Подготовка

Нужны Git и Python 3.11 или новее (`python3 --version`).

```sh
git clone <адрес репозитория с сайта>
cd <имя репозитория>
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install pytest
python -m pytest                 # примеры тестов должны пройти
```

## Как сдать задание

1. Создайте ветку: `git switch -c task-1`.
2. Решите задание в его каталоге в `tasks/`, проверьте локально: `python -m pytest`.
3. Зафиксируйте и отправьте: `git add .`, `git commit -m "Решение задания 1"`, `git push -u origin task-1`.
4. Откройте pull request в GitHub. Сайт покажет результат официальной проверки и замечания ревьюера.

Локальные тесты — для тренировки. Зачёт ставится по официальным проверкам платформы, они хранятся отдельно, поэтому менять или удалять тесты в репозитории бесполезно. Нажимать Merge не нужно: после зачёта платформа объединит pull request сама.
