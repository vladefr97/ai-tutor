# Макет основных экранов ai-tutor

Статус: **утверждён пользователем 25 октября 2026 года**. Утверждена версия с тёмным минималистичным интерфейсом, боковым чатом и встроенными в постраничную теорию вопросами (`tutor-screens-v7.html` в истории макетов). Основной файл для реализации — `tutor-screens.html`. Повторное согласование этих экранов перед началом разработки не требуется.

Утверждение относится к внешнему виду и пользовательскому потоку. Демонстрационные материалы, имитация ответов агента, временное хранение состояния и непоказанные сценарии не становятся готовой реализацией или новыми требованиями. Инженерная приёмка описана в [критериях готовности PoC](../poc-acceptance.md).

`tutor-screens.html` — автономный интерактивный HTML-макет для обсуждения интерфейса, не реализация React/Go-сервиса. Откройте файл в браузере. Данные демонстрационные; модель, почта, GitHub и БД не подключены, состояние сбрасывается после обновления страницы.

Тёмный минималистичный макет без боковой навигации. На главной — три наставника с иконками Python, Git и управления проектами. Выбор наставника открывает диалог о цели и опыте. Интервью можно пропустить после указания цели.

План представлен оглавлением: каждый модуль раскрывается в темы, практику и ожидаемый результат. Можно отправить пожелание к плану и подтвердить его. После подтверждения демонстрируется генерация, затем доступен переход к курсу. Обсуждение и генерация имитируются; изменение плана показывает заранее подготовленный пример дополнительной практики, а не ответ модели.

Курс содержит материал со встроенными вопросами, практику, историю и раскрываемое оглавление. Отдельной вкладки «Тест» нет. Теория разбита на три короткие страницы с переходами «Назад» и «Далее» и навигацией по названиям страниц. На странице последовательно идут объяснение, пример, вопрос и продолжение материала после разбора ответа. С последней страницы можно перейти к практике. Ответы и подсказки сохраняются при переходах между страницами в рамках открытого макета.

Чат расположен справа от материала; на узком экране открывается по кнопке как боковая панель. Python и Git показывают CI, ревью PR и автоматический merge; Project Management — сдачу кейса на сайте. Кабинет преподавателя показывает список учеников и просмотр их курсов. Экран задаётся параметром `screen`: `mentors`, `chat`, `plan`, `generation`, `course`, `teacher`. Материал открывается через `?screen=course&tab=theory`; старая ссылка с `tab=quiz` тоже открывает материал.

Встроенные вопросы интерактивные: по три демонстрационных вопроса для Python, Git и Project Management. Первая ошибка даёт подсказку, вторая — объяснение и правильный ответ. Вопрос отмечается как решённый самостоятельно либо с помощью. Переходы по страницам не блокируются неотвеченным вопросом. Это учебные проверки по ходу чтения; отдельный итоговый экзамен остаётся требованием продукта, но в текущем макете не детализирован.

Названия карточек: Python Developer, Наставник по Git, Project Manager. Название сайта — ai-tutor без точки. Знак открытой книги находится в `ai-tutor-icon.svg`, встроен в шапку и favicon. Отметка ревьюера в плане и отдельная галочка над заголовком завершённой генерации убраны; сам процесс ревью не отменён.

Кнопки демонстрации состояний принадлежат макету, не будущему интерфейсу ученика. Тексты и иллюстративный курс API не фиксируют состав экспертной карты. Практический финальный экзамен, другие виды вопросов и сценарии технических ошибок в этом наборе не детализированы.

Макет предназначен для проверки интерфейса. Он не подтверждает серверные права доступа, сохранение данных или реальные интеграции. Учебные материалы — иллюстративные фрагменты. Экран входа в этой версии не детализирован; согласованное требование входа по одноразовому коду остаётся в спецификации PoC.

Проверено в браузере: выбор Python-наставника, ввод опыта, получение плана, раскрытие модуля, отправка пожелания, подтверждение, демонстрация генерации и открытие курса. Проверены состояния ошибки CI и зачёта с approve/merge, кабинет преподавателя и отключённая отправка работы в режиме просмотра. На ширинах 1168 и 390 px у плана нет горизонтального переполнения, модули располагаются последовательно без наложений. Главная также проверена на ширине 390 px. В консоли ошибок нет.

Проверка встроенных вопросов: первая ошибка с подсказкой, переход на следующую страницу, возврат с сохранённым ответом и подсказкой, вторая ошибка с разбором и продолжением теории. Вкладка «Тест» отсутствует. Результаты учебных вопросов не заменяют итоговую проверку освоения навыка.
