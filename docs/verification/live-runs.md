## 2026-10-28. Интервью через сервис (#12)

`make up` без `AGENT_FAKE`, вызовы через HTTP API. Бэкенд в контейнере запускает контейнер Codex через Docker хоста. Промпт `agent-config/roles/planner.md` и основа `agent-config/directions/python/base.md` текущей ревизии. Модель планировщика `gpt-6-astra`.

1. Создание курса Python → операция `mentor_reply` succeeded. Приветствие: «Здравствуйте! Что вы хотите научиться делать на Python — например, обрабатывать файлы, считать итоги по таблицам или писать небольшие программы с нуля?»
2. Ответ ученика: «Хочу автоматизировать отчёты из Excel на работе. Немного знаю переменные и циклы. Давай на ты и покороче.» → операция succeeded. Наставник предложил ближайшую цель внутри основы (CSV, сохранённый из Excel) и вариант формулировки: «Здесь сможем работать с CSV, который можно сохранить из Excel: фильтровать строки, считать итоги и записывать отчёт. Подойдёт такой вариант — например, собирать суммы по отделам из CSV?»
3. Сохранённое состояние курса: статус `interview`; цель «Автоматизировать обработку рабочих отчётов с помощью Python; формат файлов и результат требуют уточнения.»; профиль: подготовка «немного знает переменные и циклы», контекст «отчёты из Excel на работе», предпочтения «на «ты», коротко».

Ограничение: это проверка цепочки и следования основе на одном диалоге, не измерение качества интервью.
