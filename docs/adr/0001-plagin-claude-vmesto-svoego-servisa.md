# Плагин Claude вместо собственного веб-сервиса

Продукт — генератор учебных курсов по свободному запросу: интервью с учеником, генерация курса агентом со скиллами, прохождение с помощью Наставника. Первый ученик — один человек без навыков программирования, на одном аккаунте с автором.

Решили делать это как **плагин Claude** (zip со скиллами + субагенты) и **артефакт-плеер** (HTML-страница на claude.ai с памятью прогресса через `db` и Наставником через `sample`), а не как собственный сервис. Курс — папка файлов в проекте Claude на ноутбуке ученика.

## Considered options

- **Свой сервис**: Go-бэкенд, React, Postgres, VPS, ключ OpenAI, Codex CLI в Docker как харнесс для скиллов. Отвергли: недели до первого курса, скиллы пришлось бы копировать в промпты или тащить Codex-бинарник, ключ оплачивает автор. Единственное, что он даёт сверх плагина, — масштабирование на чужих людей, что сейчас не цель.
- **Плагин ChatGPT**: интерактивный UI требует свой HTTPS MCP-сервер, прогресс без своего сервера не хранится, платформа переименовывается. Custom GPT закрываются 11.12.2026.
- **Плагин Claude** — выбрано: скиллы работают как есть, папка курса пишется и читается в Cowork/Code, артефакт даёт детерминированный плеер с хранилищем, всё на подписке.

## Consequences

- Каждому ученику нужен аккаунт Claude с платным планом; сейчас это один общий аккаунт.
- Детерминизм (порядок заданий, проверка квизов, «пройдено») живёт только в артефакте; в чате порядок ведёт модель по инструкции.
- Выбор модели по этапам ограничен тем, что даёт платформа: модель чата выбирает ученик, субагент-писатель задаёт `model` во frontmatter, в артефакте — `modelTier`.
- Если понадобится продукт для чужих людей — это новая архитектура, а не доработка.
