# Tutor App

Обучение по цели ученика в пределах экспертной основы выбранного направления. Термины описывают согласованную модель отдельного сайта; существующий Claude-прототип ещё не реализует эту модель.

## Language

**Ученик**:
Человек, который приходит со своей учебной целью и проходит обучение.
_Avoid_: юзер

**Учебная цель**:
Результат, которого ученик хочет достичь с помощью обучения.

**Направление**:
Предметная область обучения со своей экспертной основой, например Python, Git или Project Management.

**Доменный эксперт**:
Специалист, который задаёт содержательную основу направления и критерии освоения навыков. Может уточнять материалы и критерии; его участие в каждом цикле подготовки курса или обучения не требуется.

**Экспертная основа**:
Согласованные экспертом компетенции, связи между ними, критерии освоения и примеры заданий, решений и ошибок, определяющие границы поддерживаемого обучения.

**Карта компетенций**:
Описание навыков направления, их уровней и необходимых связей между ними.

**Профиль ученика**:
Предпочтения ученика о том, как с ним общаться: имя, обращение, тон и формат объяснений. Эти предпочтения сами по себе не свидетельствуют о знаниях.
_Avoid_: диагностика знаний

**Наставник**:
Агент выбранного направления, который помогает ученику двигаться к учебной цели в рамках экспертной основы, объясняет материал и даёт обратную связь по практике.
_Avoid_: помощник по любым темам

**Ревьюер плана**:
Агент, который проверяет составленный Наставником учебный маршрут по заданным критериям и возвращает Наставнику замечания для исправления. Не оценивает решения заданий ученика.

**Ревьюер работ**:
Агент выбранного направления, который проверяет выполненное учеником задание по критериям, даёт обратную связь и одобряет работу либо просит исправления. Для Project Management проверяет ответы на сайте, для Python и Git — изменения в pull request.
_Avoid_: Ревьюер плана

**Интервью**:
Диалог, в котором Наставник уточняет учебную цель, ситуацию применения знаний и исходную подготовку ученика.

**Бриф**:
Согласованное описание учебной цели, исходной подготовки и ожидаемого результата курса.
_Avoid_: ТЗ

**Курс**:
Совокупность учебных материалов и заданий для достижения одной согласованной учебной цели.

**Учебный маршрут**:
План прохождения тем и практики, выбранный для ученика.
_Avoid_: профиль ученика

**Адаптация маршрута**:
Изменение плана прохождения тем или практики по новым свидетельствам о знаниях и затруднениях ученика.
_Avoid_: настройка тона общения, подсказка к заданию

**Тема**:
Содержательная часть курса, объединяющая объяснения и практику по связанным знаниям и навыкам.

**Шпаргалка**:
Краткий справочный материал по теме.

**Задание**:
Единица учебной практики или проверки знаний с условием и критериями оценки результата.
_Avoid_: тема

**Попытка**:
Одно отправленное учеником решение задания для проверки. Несколько невыполненных требований в одном решении относятся к одной попытке.

**Разбор решения**:
Объяснение способа выполнения задания с готовым решением. Ознакомление с разбором само по себе не подтверждает самостоятельное освоение навыка.

**Итоговый экзамен**:
Самостоятельная проверка достижения учебной цели на новых заданиях по изученным навыкам.
_Avoid_: последняя тема курса, разбор решения

**Тестирование знаний**:
Проверка понимания материала с помощью набора вопросов, в том числе по коротким ситуациям.
_Avoid_: автоматические проверки программы

**Практический кейс**:
Задание применить знания к описанной ситуации и обосновать или продемонстрировать результат.

**Критерий зачёта**:
Условие, по которому результат задания или отдельной части экзамена признаётся достаточным.

**Квиз**:
Вопрос с выбором ответа из предложенных.
_Avoid_: практический кейс

**Открытый вопрос**:
Вопрос, на который ученик отвечает свободным текстом.

**Упорядочивание**:
Задание расставить предложенные элементы в правильной последовательности.

**Плеер**:
Интерфейс прохождения курса, в котором ученик читает материалы, выполняет задания и обращается к Наставнику.

**Посещение**:
Визит ученика на платформу, относящийся к определённому моменту времени.

**Всего учеников**:
Количество уникальных учеников, хотя бы раз посетивших платформу.

**Регулярно активный ученик**:
Ученик, посетивший платформу минимум в два разных дня за последние семь дней. Это характеристика посещаемости, а не подтверждение учебного прогресса.

**Преподаватель**:
Человек, который просматривает цели учеников и историю их обучения: интервью, задания, ответы, оценки и прогресс. Эта роль отличается от подготовки экспертной основы направления.
